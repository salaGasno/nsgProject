# Production Line Conveyor-belt Introduction

This project consists of a PLC system utilizing a state machine to control a conveyor-belt
and several pneumatic outputs.

This project was completed at the Automated Controls Installation and Maintenance program
in BCIT during ACIM-5010: "PLCs".

This course served as an introduction to PLC systems. However, as a Mechatronics Technologist
most of the topics covered in this course were known to me. As a result of this, I had decided
to create the following PLC system utilizing a state machine where one was not required to
complete the project.

## System Components

This PLC system consists of the following hardware:
-1769-L30 Allen Bradley PLC
-PowerFlex 70 EC_I
-Conveyor Belt System Provided by the ACIM program.
